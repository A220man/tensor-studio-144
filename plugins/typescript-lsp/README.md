# TypeScript LSP Plugin

Provides TypeScript/JavaScript language server support via `typescript-language-server`.

## Installation

```bash
npm install -g typescript-language-server
```

## Configuration

The plugin uses the standard `.lsp.json` configuration format. See [plugins reference](https://code.claude.com/docs/en/plugins-reference#lsp-servers) for details.

## Supported Languages

- TypeScript (.ts, .tsx)
- JavaScript (.js, .jsx, .mjs, .cjs)
